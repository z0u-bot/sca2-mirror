# Glossary of preferred terms

Partly done: the `style-terms` skill now defines condition / run / cell / arm / seed / criterion, and ex-2.1.6/7/8 were edited to conform (cell is reserved for literal grid entities; condition × seed is a "run"). Still to document there: "rung", "gate", "partial" vs "named contrary reading" (ex-2.1.7's H3 distinguishes these: a partial is a weaker pass, a contrary reading is a preregistered interpretation of a miss), and the loss-weight symbol scheme adopted in ex-2.1.7: λ subscripted by term (λ_a anchor, λ_s̄ anti-subspace; bar = repulsive), replacing the one-off μ.
